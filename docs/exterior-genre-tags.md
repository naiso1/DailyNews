# 外装のジャンルタグ

2026年9月30日、開発室からの39キーワードを個別タグへ反映。従来のグリル・バンパーなども含め50ジャンル。ニュースの採用基準とは別に、掲載された見出し・要約に記載された主題を探すための分類とする。

- 定義は `dailynews/exterior_tags.py` に集約。日本語・英語・中国語の表現と略語を対応させる。
- 変更後は `python -m dailynews.exterior_tags` で配布用 `dailynews_exterior_tags.js` を更新する。テストで生成物とPython判定の一致を確認する。
- Pythonの公開処理とブラウザが同じ定義を使う。既存記事もブラウザで再分類し、古い保存タグや応用アイデアから主題を作らない。
- 全一致タグを残す。以前の6件／8件上限を外装には適用しない。画面の「もっと見る」で全ジャンルを展開できる。
- 外装のジャンル絞り込みは分類済みタグに一致させる。通常のキーワード検索は引き続き本文の文字列検索。
- `軽量化` の旧URLは `軽量` に、`材料` は `新素材` に、`外装加飾` は `加飾` に、`センサー透過` は `センサー対応` に読み替える。
- 内装の分類・収集基準は変更しない。タグの追加だけで該当記事が増えるわけではなく、該当なしのジャンルも選択肢に表示する。
