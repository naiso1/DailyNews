# 考察を短くするときの引用保持

考察は420字以内を目安に短縮します。ただし、短縮前に日本語・各文の参照・利用可能な記事IDのみという検査を通っていた文章が、短縮後の最終正規化で参照検査を通らなくなった場合は、検査済みの短縮前の文章を保持します。内装・外装の両方に適用します。

この場合は420字を超えることがあります。`[ANALYSIS] Shortened citation validation failed` のログに実際の文字数・目安・超過有無を記録します。字数を合わせるために参照を切り落としたり、合格させるために引用を追加したりしません。

元の文章も参照検査に不合格の場合、この処理は合格扱いに変更しません。外装の既存の完成確認・公開停止条件は維持します。`[IDEAS] accepted 2/2` は企画例が2件できたことを示すログで、考察の検査合格を意味しません。
