# 内装版の二輪記事の選定調整（2026-09-30）

## 原因

内装関連度の採点では二輪を18点以下へ下げていたが、国別の最大10件への補充では非対象・低得点の記事も候補に残っていた。二輪のTFT、メーター、シートを内装情報と判定する経路もあり、公開処理は収集結果をそのまま受け入れていた。低い点数だけでは二輪の除外を保証できなかった。

## 今後の条件

- バイク・スクーターやライディング用品が主題の記事を、内装版の掲載候補から除外する。高得点や画像があっても採用しない。
- 原文見出し、原文の冒頭、二輪カテゴリのURL、二輪と特定できる製品名で確認する。記事の関連記事欄だけを根拠に除外しない。
- 乗用車の自転車積載・収納、原文に乗用車内装への具体的な実装がある技術は残す。一般的なTFTやシート、AIが生成した転用アイデアは例外の根拠にしない。
- 通常候補・件数補充の両方に先立って適用し、CSVからの直接公開・途中再開時にも新規記事を確認する。二輪で件数を埋めず、該当記事だけを除外して残りの処理を続ける。
- `dailynews/interior_vehicle_scope.py` を収集・公開で共用する。除外理由は実行時の `editorial_policy_review.json`、公開直前に検出した場合は実行ログに残す。

今回の変更は次回の選定向け。過去の掲載済み記事や、そのIDに紐付く閲覧・コメント等は書き換えない。二輪以外の採点・補充ルールや外装の選定には今回変更を加えない。

## 確認

実際に再発した二輪記事の見出し・要約・URLと、乗用車収納／素材記事を残す境界例を回帰テストに保存した。高得点の二輪、非対象・低得点の補充候補、直接CSV公開でも除外されることを確認する。

次回は地域別の除外件数と残った記事の有用性を確認する。件数だけを理由に除外を解除せず、不足する分野の画像付きRSSを検討する。
