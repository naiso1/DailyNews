# ランキングの総合点

2026-09-28 変更。内装版・外装版のニュース／論文ランキングに共通で適用する。

閲覧は記事への関心を示すが、内容への満足を意味しない。総合順位では、コメント、いいね、閲覧の順に1件あたりの重みを付ける。

```text
総合点 = コメント数 × 5 + いいね数 × 3 + min(閲覧数 × 0.05, 1)
```

- 旧式は `いいね数 × 3 + コメント数 × 2 + 閲覧数`。閲覧が多いだけで反応のある記事を追い越しやすかった。
- 閲覧の加点は20回で上限1点。閲覧だけでは、いいね1件（3点）やコメント1件（5点）を上回らない。
- 総合点が同じ場合は、コメント数、いいね数、閲覧数、新しい日付の順に比較する。
- 「閲覧数」「いいね」「コメント」を選んだ場合は、それぞれの件数で並べる。
- 蓄積済みの件数は変更しない。過去の記事にも同じ計算を適用する。

検証: `node tests/test_ranking_score.cjs`。大量閲覧だけの記事より反応のある記事が上になること、閲覧加点の上限、ニュース／論文両方の描画、各個別ソート、ローカル閲覧数、反応なしの場合を確認する。
