# 展示会タグ

内装・外装の共通UIで、通常ジャンルより前に次の順序で表示する。

1. CEATEC×JMS2026
2. パリモーターショー2026

CEATECとJapan Mobility Show Bizweekはどちらかへの言及で同じタグを付ける。
日本語・英語・フランス語・中国語の代表表記に対応する。

- 正本は `dailynews/event_tags.py`。変更後は `python -m dailynews.event_tags` でブラウザー用の `dailynews_event_tags.js` を生成する。
- 既存記事は表示時にタイトル・要約・出典抜粋・記事URLから判定する。記事ID、日付、画像、閲覧履歴は変更しない。
- 新規掲載は原題・原文も判定し、要約で展示会名が省略されても `eventTags` に保持する。通常ジャンルの件数上限によって展示会タグは落とさない。
- 取得本文・保存済み本文とも、Yahoo!ニュースの「【関連リンク】」など、CNEVPostの「Related Posts」など、サイトごとの既知の推薦欄以降を判定から除く。本文で実際に展示・取材している記事は残す。ブラウザーと公開処理は同じ除外規則を使う。
- 展示会名に結び付く開催年を優先する。年が省略されている場合は2026年の記事だけを対象とし、昨年・16年前などの回顧表現がある場合は自動付与しない。車両のモデル年を展示会の年として使わない。
- タグは絞り込み用で、記事の採用基準、地域ごとの件数、画像URLの条件を緩めるものではない。

## 2026-10-16の収集補強

`dailynews/event_collection.py` にCEATECとJMSの専用検索を定義。対象記事日付が
2026-09-15〜10-23に入る場合だけ、日本のGoogle News RSS検索に2検索を追加する。
通常の製品検索を置き換えず、有料検索APIの呼び出しは増やさない。
専用検索は日付を絞ってから各検索15件の取得上限を適用し、古い告知が先に並ぶことで対象日の記事を見落とさないようにする。
AI審査前の既存件数枠内で、日本のCEATEC・JMS候補を最大3件優先する。
外装の複数日処理は新しい日付からの順序を保つ。最終の関連性審査、画像条件、
重複排除、国別の掲載上限は変えないため、検索で見つかった記事が必ず掲載されるわけではない。

10月16日公開分は、関連リンクだけで付いたパリの保存タグを内装2件・外装2件で訂正。
会場でのインタビュー・実車展示に基づく保存タグは原文と照合して保持した。

全期間のタグ候補137件（内装61件・外装76件、両版の同一URLを別件として集計）を点検した。
訂正対象は内装 `jp2039`・`cn1820`、外装 `jp213`・`jp215`。
原文の会場取材・展示発表・出展予定が確認できるものは保持した。
