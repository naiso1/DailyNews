# 外装版の考察・アイデア生成からの再開

2026-09-30に、記事28件の収集後、日本の考察に出典のない文が残り、インドのアイデアが1件だけになって公開が停止した。公開完了の記録を進めない確認処理は正常に働いていたが、途中保存からの再開が自動実行されていなかった。

## 対策

- 未完成の考察・アイデアだけの失敗を `ExteriorInsightsIncomplete`（終了コード75）として識別する。その他の異常を同じ扱いにしない。
- 実行管理側は同じ日付の収集CSVを検証し、同じ記事・途中保存から最大2回追加で再開する。収集・Git公開・配信処理はこの再試行には含めない。
- 再開時は国別の出典情報の一致を確認し、完成済みの考察とアイデアを再利用する。出典や2案の確認を省略して公開しない。
- 完成した案が2件のうちどちらだったかにかかわらず、実際の参照記事IDを使って不足案の根拠を選ぶ。未使用記事を優先し、追加試行では候補を切り替える。
- 考察だけの再生成は専用の短い指示とし、導入と結論も含め各文へ根拠を求める。プログラムで無関係な参照IDを付け足さない。

## 手動復旧の入口

公開前の確認が必要なときは、処理PCの通常の実行入口で外装だけを再開できる。

```powershell
& "$env:LOCALAPPDATA/DailyNewsRuntime/venv/Scripts/python.exe" -B deployment/workstation/run.py --edition exterior --resume-from-sheet --build-only
```

完成後に内容・画像・日付を確認し、通常の外装実行で公開する。収集CSVの日付が古い場合は再開できない。Web公開の成功とメールの実送信は別の記録として確認する。
